# Goal OS — Personal Progress & Developer System

A lightweight, distraction-free progress and growth tracker tailored around four pillars:
- 🎮 **Game Engineering & Architecture:** Shipping prototypes, systems, profiling, and milestone roadmaps.
- 🧠 **Daily LeetCode & DSA Practice:** Tracking Java solutions, interview readiness matrix, and live profile sync.
- 🚀 **Game-Dev Brand & Content:** Devlogs, lessons learned, and public sharing.
- 🏃 **Health & Sustainability:** Reaching 75 kg sustainably with interactive trajectory graphs, daily hydration, and movement.

---

## ✨ Features in Goal OS v4.0

1. **📊 Visual Growth & Analytics Dashboard:**
   - **Weekly Completion Momentum:** Compares completion rate this week vs last week (+/- %).
   - **Focus Effort Bar:** Visual breakdown showing exact percentage of effort spent in DSA, Game Dev, Health, and Personal.
   - **Weight Loss Trajectory SVG Graph:** Dynamically plots actual logged weights against the green dotted 75.0 kg target baseline.
   - **DSA Interview Readiness Matrix:** Pattern-wise preparedness bars across core topics (Arrays, Sliding Window/Stack, Binary Search, Trees, Graphs, DP).

2. **🎯 "Daily One Big Thing" (North Star Focus):**
   - Prominently anchors your single highest-leverage task for today right at the top of the dashboard to eliminate cognitive overload after office hours.

3. **🔄 Smart Task Rollover:**
   - Automatically detects unfinished tasks from previous days and offers a 1-click banner to move them into today's list or dismiss them.

4. **🎯 Goal Breakdown (Parent Goal ➔ Sub-milestones Checklist):**
   - Break large game engine milestones into concrete sub-tasks with interactive checkboxes.
   - Parent goal percentage automatically recalculates based on completed sub-milestones.

5. **🔗 Live LeetCode Profile Sync:**
   - Enter your LeetCode username and click `Sync Live Stats` to fetch your real solved problem counts directly from public stats.

6. **👤 Account, PIN Lock & Free Cloud Sync:**
   - User profile with personal greeting and optional 4-digit security PIN lock.
   - Built-in Supabase cloud connection to auto-sync your tracker between your laptop and mobile device.
   - Offline-first fallback: 1-click JSON backup and CSV task history exports.

7. **🍅 Deep Work Pomodoro Focus Timer:**
   - 25m Pomodoro, 50m Deep Work, and 5m Break modes with audio bell alerts and confetti upon completion.

8. **🧠 Spaced Repetition Flashcards:**
   - Preloaded with high-yield DSA templates and Game Engine architecture concepts with interactive 3D flip cards and rating controls.

9. **🌓 Sleek Dark & Light Mode:**
   - High-contrast OLED/navy theme and clean light theme with instant header toggle.
